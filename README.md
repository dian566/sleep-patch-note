## How to run

```sh
python3 main.py
```

No dependencies beyond the Python standard library. Any Python 3
interpreter works; the program only reads one environment variable,
`OUTPUT_PATH`, to decide where the entry file goes.

## What it writes

Running the program drops a single 119-character patch note into
`/output/entry.txt` — one line, no trailing newline:

> Fixed: sleep no longer ships with a 45-minute ceiling-staring loading screen. It now starts the moment your eyes close.
